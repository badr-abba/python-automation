# 🔨 Module 6 : Projets Pratiques

C'est l'heure de vérité. Nous allons combiner tout ce que nous avons appris pour créer 3 scripts utiles dans la vraie vie d'un Admin Sys / DevOps.

## 🎯 Objectifs
- Structurer un script complet.
- Gérer les erreurs et les logs.
- Produire un résultat concret.

## 📂 Contenu du Module

### PROJET 1 : Le Nettoyeur (`01_cleaner.py`)
- **Problème** : Votre dossier "Téléchargements" est un bordel.
- **Solution** : Un script qui déplace automatiquement les fichiers dans des sous-dossiers (`Images`, `Documents`, `Installeurs`) selon leur extension.
- **Compétences** : `os`, `shutil`, `pathlib`.

### PROJET 2 : Le Surveillant (`02_monitor.py`)
- **Problème** : Vous voulez acheter un produit, mais seulement quand son prix baisse.
- **Solution** : Un bot qui vérifie le prix sur une page web simulée et vous alerte si c'est une bonne affaire.
- **Compétences** : `requests`, `BeautifulSoup`, `time`.

### PROJET 3 : Le Reporter (`03_reporter.py`)
- **Problème** : Votre boss veut un résumé des ventes tous les matins.
- **Solution** : Un script qui lit un CSV brut, calcule des totaux/moyennes et génère un rapport texte propre.
- **Compétences** : `csv`, `maths`, `f-strings`.

## 🚀 À vous de jouer !
N'hésitez pas à modifier ces scripts pour les adapter à vos besoins réels.
